# Happenings flyers

The /happenings page displays three flyer images, in this order:

1. restaurant-week.jpg   — Horsham Restaurant Week (prix fixe) flyer  [shown first]
2. happy-hour.jpg        — Happy Hour / daily specials flyer          [shown second]
3. eagles-specials.jpg   — Eagles game-day specials flyer             [shown third]

The files currently here are on-brand PLACEHOLDERS. Replace each one with the
real flyer, keeping the exact same filename, and the /happenings page updates
automatically. Portrait images (roughly 3:4) look best. JPG or PNG both work
(if you use PNG, keep the .jpg filename or tell us to update the reference).
