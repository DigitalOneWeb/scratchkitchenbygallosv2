# Happenings flyers

The /happenings page displays these three flyer images, in this order:

1. restaurant-week.jpg   — Horsham Restaurant Week (prix fixe)   [shown first]
2. happy-hour.jpg        — Happy Hour / daily specials           [shown second]
3. eagles-specials.jpg   — Eagles game-day specials              [shown third]

To update a flyer later, replace the matching file here with the new image,
keeping the exact same filename, and the page updates automatically. Portrait
images (roughly 3:4, e.g. 926×1239) look best.
